# Установка «Смета Тизими» для Windows x64

Скачайте установщик и `installer-manifest.json` из официального источника проекта.
Имя установщика указано в поле `file`, размер в байтах — в поле `bytes`.

Откройте PowerShell в папке загрузок и выполните:

```powershell
$m = Get-Content -Raw -LiteralPath '.\installer-manifest.json' | ConvertFrom-Json
Get-FileHash -Algorithm SHA256 -LiteralPath (Join-Path $PWD.Path $m.file)
$m.sha256
```

Сравните выведенный `Hash` с `sha256` из официального манифеста. Регистр букв
не влияет на результат. При несовпадении остановитесь и обратитесь в поддержку.
Совпадение хеша подтверждает совпадение файлов. Доверие к манифесту зависит
от источника, из которого он получен.

Если в поле `signature` указано `NotSigned`, у установщика отсутствует цифровая
подпись. Windows может показать предупреждение о неизвестном издателе или
заблокировать запуск через Microsoft Defender SmartScreen.

Только после подтверждения официального источника и точного совпадения SHA-256,
если политика устройства разрешает запуск, в предупреждении SmartScreen могут
быть доступны «Подробнее» и затем «Выполнить в любом случае». Если действие
недоступно или запрещено политикой, обратитесь к администратору или в поддержку
проекта.

Следуйте инструкциям мастера. Установка выполняется для текущего пользователя.
