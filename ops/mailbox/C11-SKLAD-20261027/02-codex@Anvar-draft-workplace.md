# C11 — редактирование, подтверждение, голос и периодный Excel

Владелец уточнил: ежедневный приход/расход должен вводиться непосредственно в системе; Excel нужен для переноса начальной книги и выдачи отчетов. Эта часть PR — безопасная подготовка приходной книги, не завершенный ежедневный складской учет.

- Для каждой строки: правка даты, материала, единицы, количества, поставщика, номера документа; исходная строка остается неизменной. Любая правка инвалидирует полное подтверждение и прежний результат поиска дублей.
- `sheb` находит кириллические варианты материала. Предлагаются реальные варианты единиц и поставщиков из выбранной книги; совпадение при поиске не объединяет движения и не конвертирует единицы.
- Голос/аудиофайл отправляется только явной кнопкой в server-only endpoint из PR182. Есть запись микрофона до60сек, ограничение размера, отмена/очистка при смене компании и освобождение microphone tracks. Распознанный текст редактируется. Бounded matcher предлагает только найденные в каталоге поля; неоднозначность остается видимой, команда расхода в приходном редакторе не применяется. Это не универсальный AI parser всех устных операций.
- RU XLSX за включительный период: только явно подтвержденные локальные черновики. Реестр, свод по точному имени+единице и источник/SHA. Метка НЕ ПРОВЕДЕНО; неизвестные цены/НДС/начальный/конечный остаток не подставляются нулями. Не введенный расход не считается подтвержденным нулем. Изменение компании отменяет запоздавшую выдачу файла.
- Никаких warehouse/financial writer calls и никакого импорта остальных листов. Реальный файл и финансовые сведения не опубликованы.
