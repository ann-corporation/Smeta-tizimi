## Результат и граница

Добавлены самостоятельный менеджер ephemeral AES-GCM сессии и opt-in loader,
который открывает кэш только после текущей онлайн-авторизации точного объекта.
Общий boolean не считается правом объекта. 401 не даёт fallback; 403 очищает
кэш и сохраняет server-authorized legacy fallback с отдельным билетом против
поздних ответов. Logout/switch/new read/TTL отменяют этот билет.

Ключ non-extractable и не сохраняется. Refresh/switch создают новый ключ после
очистки старых записей. UI/память закрываются синхронно; зависшая очистка блокирует
только новое открытие кэша. Default-off reader не ждёт эту очистку.

Три native-команды переведены под явный app manifest ACL с локальной capability,
проверкой реального origin/main webview до credential IO, TTL и поколением
записи против delayed refresh после logout. Новый IPC-контракт описан в
`docs/architecture/DESKTOP_SESSION_LIFECYCLE.md`.

Это prerequisite branch, не full hook и не готовый offline product. Runtime hook,
auth, middleware, bootstrap и D7 lease не подключены. Существующий dirty worktree
`C:/Temp/GAS-desktop-integrated` не изменялся. D2/D3 пути не изменялись.
Внешние сессии, production и реальные пользовательские credentials не читались
и не записывались.
