## Checked, no defect

- Money: QQS bilan is the large figure, then ustamali (QQS siz), then ustamasiz (QQS siz), everywhere (hub list, object card, smeta header, Rahbar). Unknown = em dash (unit-tested), "1 ta qator narxsiz — jami to'liq emas" warning present. Row qoldiq `-0,3` is red and keeps its sign; entered volume `-5,5` is kept ("−5,5" in draft, red) and explained ("Minus hajm: qatorning faktidan ayriladi").
- Smeta tree: expand/collapse all, KATTA HARF row titles (server text, shown as stored), per-section Fakt/F-2 bars, search field.
- Fakt entry -> draft -> outbox: queued / rejected (reason + Tahrirlash / Qayta yuborish / O'chirish) / sent (document no., over-estimate warning, unpriced rows) all render.
- Back stack: object card -> smeta -> fakt dialog -> back returns step by step. Rotation and `am kill` (process death) on Jarvis: conversation and object scope restored.
- Rahbar cabinet: Rahbar panel (ring, totals QQS bilan first, cash flow) and switcher chip render.
- Ombor list, search, scanner button, Kirim / Chiqim; Profile (username, PIN, language, theme, sign out, version).
- Touch targets: Material chips and buttons use 48 dp minimum interactive size; the only sub-48 dp problem found was D2.
