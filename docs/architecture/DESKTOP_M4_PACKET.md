# Desktop M4 — обновление пакета

Изолированный адаптер использует существующий зашифрованный ObyektOmbor. Адаптеру передаётся эксклюзивный экземпляр хранилища текущей сессии и авторизованный reader D2. Условный запрос привязан к последнему объекту и ETag; неподтверждённый 304 не открывает диск. 401/403 закрывают хранилище. Пакет без поля f2_summa_yoq или метаданных собственного подвала отклоняется; исходный пакет сохраняется без денежного пересчёта.

Основа обновлена до main 9a6d4ec1 (PR243): D2/D3 и менеджер PR237 уже включены. Подключение к экрану и разрешение чтения офлайн остаются открытыми: нет подписанного lease M3 и законченного native login. Ошибка сети не открывает кэш. Это не подтверждение готовности M4.

Синтетический тест проверяет 200 → AES-GCM → подтверждённый 304 → повторное чтение ciphertext тем же ключом → очистку при закрытии. NULL F2 и собственный подвал сохраняются. Чтение новым экземпляром хранилища помечается serverTasdiq=false: это проверка сохранности, а не разрешение офлайн-доступа.
