# Desktop M4 — обновление пакета

Изолированный адаптер использует существующий зашифрованный ObyektOmbor. Адаптеру передаётся эксклюзивный экземпляр хранилища текущей сессии и авторизованный reader D2. Условный запрос привязан к последнему объекту и ETag; неподтверждённый 304 не открывает диск. 401/403 закрывают хранилище. Пакет без поля f2_summa_yoq или метаданных собственного подвала отклоняется; исходный пакет сохраняется без денежного пересчёта.

Подключение к экрану, актуальная проекция D3 и разрешение чтения офлайн заблокированы до интеграции D2/D3 и подписанного lease M3. Ошибка сети не открывает кэш. Это не подтверждение готовности M4.
