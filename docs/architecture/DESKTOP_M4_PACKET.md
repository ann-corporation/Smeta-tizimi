# Desktop M4 — пакет по подписанному lease

Зависит от #246 (ADR-DESKTOP-AUTH); ветка включает его commits, PR остаётся base main. Установленная desktop-сборка подключает native transport и кнопку «Oflayn obyektlar», web entry/main.tsx не меняются.

Онлайн: native actor/device/generation → обновление Ed25519 lease → проверка подписи/срока/company/object/read permissions → условный GET пакета → зашифрованная запись через Rust. Ключ AES-GCM остаётся в Windows Credential Manager. Сохраняются исходный пакет, ETag и подписанный lease с high-water времени.

Без сети: проверяются сохранённый lease, точный actor/device/company, объект, срок и откат часов; только после этого читается packet/company/object. Перезапуск renderer не меняет ключ. При подключении lease обновляется раньше показа снимка; 304 принимается только с совпавшим сохранённым пакетом/ETag. 401/403 закрывает данные, удаляет локальный кэш и native credential. Обычная web-память тоже сбрасывается reload. Ошибка очистки блокирует текущий runtime.

Отдельное окно — только чтение, без очереди команд. Объекты онлайн поступают из существующего /api/sb, офлайн — только из проверенного lease и сохранённых пакетов. Смета/факт/остатки используют существующую materialization и lib/hisob-yadro. Таблица показывает по150 строк, а не весь большой объект в DOM. NULL остаётся неизвестным. f2_summa_yoq и собственный t2_akt_podval сохраняются без пересчёта; доступные замороженные итоги документа отображаются существующим QiymatUchlik, QQS первым. Отсутствующий серверный summa_paket не заменяется суммой по догадке.

Проверки: 81 focused client/server/i18n test PASS, включая200→сохранение→новый runtime без сети→304, истечение/подделку/чужую компанию/отзыв/часы назад. App TypeScript, scoped lint(0ошибок) и desktop Vite build PASS; полная зелёная CI не подтверждена. Модульный fake native port не доказывает шифрование: оно проверено отдельными Rust тестами, сквозная установленная сборка — M5.

Production не изменялся. L0 применяет миграцию #246 и задаёт signing env/build public key отдельно. M5 локальный тестовый backend и production acceptance разделены.
