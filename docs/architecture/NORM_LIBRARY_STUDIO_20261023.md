# Подключение именованной нормативной библиотеки

Источник: неизменяемый review-release `66bb1a23bd18c63006d447b5`, версия источника 2.8.1. 48 083 работы, 112 сборников, 8 084 таблицы, 432 277 строк ресурсов. Это отдельный корпус, а не исправление похожих кодов старого каталога.

## Порт и идентичность

`/api/norm-library` требует существующую сессию и читает только фиксированный whitelist файлов из private R2. Архивы передаются исходными байтами без HTTP Content-Encoding: клиент проверяет размер и SHA-256 перед распаковкой. Навигация и индекс загружаются при выборе библиотеки; состав ресурсов — по выбранному сборнику. Старый `/api/norm-katalog` и его CURRENT не меняются.

Работы имеют ID `norm-library:<revision>:<literal source key>`. Ресурсные строки идентифицируются работой, source document и позицией, поэтому одинаковый код ресурса не склеивает разные нормативные строки. Печатный шифр ресурса сохраняется отдельно от ID. Разделы и таблицы строятся по явным исходным parent keys, включая ремонтные таблицы непосредственно под сборником. Е40 использует исходную ссылку на документ; отсутствующее официальное название не выдумывается.

## Единый ручной и AI сценарий

Studio позволяет выбрать библиотеку; выбор сохраняется на устройстве. Переключение отменяет применение устаревших ответов, сбрасывает выбор в каталоге и отделяет AI conversation cache новой редакции. Уже добавленные работы остаются замороженными снимками, смена библиотеки их не переписывает.

Ручное добавление и AI используют `snapshotWork`, `catalogueBasis` и существующие ADD_OCCURRENCE/BATCH/SET_COEFFICIENTS. Отдельного расчетного ядра нет. Явные физические единицы и масштабы из поля measure разбираются ограниченным парсером; неподдерживаемые/составные единицы требуют ручного основания. Исходные единицы не объявляются наблюдениями старого KodI. Источник, единица и scale сохраняются в основании.

Литеральные единицы ресурсов сохраняются в namespace редакции. Категории labour/machinist/machine/material передаются явно: язык названия не определяет категорию машиниста. Противоречие группы и единицы остается UNRESOLVED. Нормы, NULL и явные нули сохраняются; экспоненциальная запись маленьких чисел разворачивается без округления.

Read-only проверка выявила 101 исходную строку material с единицами времени труда/машин: 85 чел.-ч, 15 маш.-ч, 1 в 1000маш.-с. Эти строки сохраняются, но получают RESOURCE_GROUP_UNIT_CONFLICT и не идут в автоматическое материальное ценообразование. Ставка строителя не применяется к машинисту, в том числе с узбекским названием. Смешанный экспорт берет нормативную единицу из замороженной работы/основания, поэтому смена выбранной библиотеки не теряет масштаб 100/1000.

## Коэффициенты и ограничения

Новая редакция использует только свои правила и native scope: collection/section/table/row-range. Старые коэффициенты не подставляются новой работе по похожему коду. Ручной выбор, AI summary, AI selection и применение получают одинаковый список source-qualified кандидатов. Условия применимости остаются видимыми; подбор не означает автоматического принятия всех правил. Принятое изменение проходит существующую отменяемую команду.

Пакет остается REVIEW_ONLY и не содержит цен. Отсутствующая цена остается NULL. 2 411 норм без ресурсного состава нельзя добавить как готовую расчетную работу. 948 исходных записей без measure не получают выдуманную единицу. Этот релиз не объявляет весь источник юридически утвержденным и не заменяет проверку применимости редакции для объекта.

## Проверка и координация

Регрессии покрывают whitelist/auth/raw gzip, SHA corruption, источник/редакцию, parent hierarchy, resource groups/units, маленькие нормы, AI/manual basis, source-scoped коэффициенты и поздние UI/AI ответы. Дополнительный локальный прогон `NORM_LIBRARY_FIXTURE_ROOT=<external release folder> npx vitest run src/lib/catalog-extraction/norm-library.local.test.ts` проверяет весь исходный пакет, не добавляя его файлы в репозиторий.

Обязательны app/functions TypeScript, lint, tekshir, build, unit tests и exact-SHA CI перед main. Факт production deployment и authenticated GUI smoke фиксируются отдельно в Obsidian/mailbox. В этой сессии GUI инструменты недоступны; CI и HTTP health не выдаются за owner acceptance. Изменения соседнего Claude PTO/F2/import lane сохраняются при merge main; его задания не закрываются этим релизом.
