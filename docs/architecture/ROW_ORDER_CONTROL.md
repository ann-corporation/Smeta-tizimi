# Управление порядком пользовательских строк

Статус: реализация начата, не полное покрытие системы.

Общий контрол: вверх/вниз, текущая позиция/количество, ввод целевой позиции и применение Enter или кнопкой. Нумерация начинается с 1. Пустые, дробные и выходящие за границы позиции не применяются. Перемещение сохраняет идентичность, значения и исходный шифр строки.

Подключено: работы Studio через MOVE_OCCURRENCE, разделы Studio через MOVE_SECTION, товары новой фактуры через порядок массива существующей команды сохранения. В Studio позиция относится к полному списку внутри родителя, включая строки, скрытые поиском/пагинацией. Действуют прежние undo и сохранение черновика.

Следующие интеграции: комиссия АОСР, объекты оферты, дополнительные работы F2. Эти файлы имеют действующие чужие leases; интеграция требует координации. Для F2 обязательны штатная команда, expected version, operation id, ограничения исходных строк и привязки замены. Исторические документы и хронологические реестры нельзя объявлять произвольно перенумерованными посредством локального массива. Для реестров нужен отдельно обозначенный персональный порядок представления.

Не считать этот первый набор полным выполнением требования владельца по всем пользовательским спискам. Production не обновлена этим документом.

Усиление: в начало/конец одной кнопкой, Alt+↑/↓ и Alt+Home/End, сброс незавершённого ввода при внешней смене позиции/числа строк. Группа выбранных Studio works перемещается внутри каждого прежнего раздела с сохранением взаимного порядка и одним undo. Контролы фактуры заблокированы во время сохранения. RU/EN переводы добавлены. Исправлена CSS-структура панели разделов.
