# Аудит библиотеки норм и общего импорта — 23.10.2026

## Подтвержденная ошибка приложения

Один и тот же синтетический XLSX, ранее экспортированный установленной программой, прочитан двумя независимыми путями. Текущее ядро источника 2.8.1 видит три листа. Общий `readXlsx` до исправления возвращал успешный workbook с нулем листов. Причины: регулярные выражения ожидали непредваренные namespace-prefix теги; разбор relationships зависел от порядка Id перед Target. Экспортер использует x:sheet/x:row/x:c и Target перед Id.

Исправление сделано в единственном общем reader: известные OOXML namespaces распознаются по URI, атрибуты не зависят от порядка, абсолютный package target сохраняет прежнюю нормализацию, отсутствующая связь или XML листа дает явную ошибку. XML-текст, формулы и исходные числовые строки не преобразуются в другие значения. Новые synthetic regression cases проверяют shared strings, формулу, numericText, outline, merged cells и hidden-sheet flag. Реальные сметы в репозиторий не добавлены.

После исправления тот же XLSX дает три листа, основную ЛРВ, одну работу Ц01-01-001-1 объемом8.7 и шесть ресурсов. Сохранены нормы на единицу10.3/3.02/1.2/1.2/0.62/3 и рассчитанные из исходного файла количества89.61/26.274/10.44/10.44/5.394/26.1. Неизвестная цена остается NULL; исходный явный ноль не заменяется догадкой.

## Новая воспроизводимая библиотека

`library-release/manifest.json`, revision66bb1a23bd18c63006d447b5. Полный индекс работ, дерево,112 отдельных collection shards, исходные resource recipes и коэффициентные правила/targets. Для каждого сборника manifest содержит путь, размер и SHA256: полный SQLite не нужен браузеру для открытия одной ветки. Все48083 работы имеют проверенный родительский table_key; исходные значения не переписаны. Укороченные ремонтные коды Е51-1-1 не проходят через грамматику нового строительства Е01-01-001-1.

Проход текущего repository API Collections→Otdels→Tables→NormsOfTable дал45094 работы. Остальные2989 восстановлены в новой навигации через явный norm.table_key, без выдуманного раздела. Это ограничение конкретного traversal, а не доказанный дефект GUI: отдельные document/repair routes GUI в этом запуске не исследованы.

У Е40 исходное название сборника пустое. Сохранен факт отсутствия source title; display label содержит код и исходный документ дополнения. Это не выдуманное официальное название. В текущем source также2411 норм без рецепта и948 без measure; к автоматическому расчету они не допускаются. Данные новой библиотеки имеют REVIEW_ONLY/calculation_approved=false.

R2 публикация: `norm-library/review-releases/66bb1a23bd18c63006d447b5`,117 объектов. Подтверждение только в `R2_LIBRARY_RECEIPT.json`: каждый объект скачан обратно и сверен SHA256, manifest опубликован последним. Активный указатель не переключался: разные редакции нельзя соединять только по похожему шифру.

## Граница аудита и дальнейшая интеграция

GUI инструменты текущей сессии недоступны; свежий GUI smoke меню/импорта не заявляется. Оригинальные пользовательские большие XLS/PDF в этом запуске не прогонялись. Подтверждены actual installed core/database behavior и одинаковый synthetic XLSX в двух reader pipelines.

Для включения новой библиотеки в рабочий каталог нужен явный выбор источника/редакции, source-qualified IDs, раздельный поиск и области поправок; нормализация похожих букв допустима для поиска, но не для слияния норм. До переключения обязательны coverage gate без потери работ, контракт единиц/масштаба, recipe parity и эталон импорта. Текущий audit не объявляет такое переключение или весь глобальный rollout завершенным.
